03 · NeRF（Mildenhall et al., ECCV 2020）

NeRF：把整個場景存成一個函數

F( x, y, z, θ, φ ) → ( RGB, σ )

輸入（5D）

位置＋視角

空間中的一點 (x, y, z)，以及從哪個方向 (θ, φ) 看它

輸出

顏色＋密度

這點是什麼顏色 RGB、有多「實」σ（光在這裡被擋住的程度）

關鍵設計

σ 只看位置

顏色才看視角 → 幾何在各角度一致，又能表現反光

函數用一個 8 層、256 通道的全連接網路（MLP，不是 CNN）表示。比喻：一團會回答問題的彩色霧。

Wiki：concepts/radiance-field.md、sources/nerf.md ｜ 來源：NeRF Sec. 3

這個函數就叫做輻射場（radiance field）。你問它：這個點、從這個方向看，是什麼顏色？有多濃？它就回答。為什麼密度不能隨視角變？因為一個物體不會因為你換個角度看就變透明——這個限制讓多視角的幾何保持一致。
